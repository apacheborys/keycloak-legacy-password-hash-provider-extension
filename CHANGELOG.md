## [0.0.1] - 2026-03-28

### Added

- Keycloak password hash provider extension for legacy `argon/argon2/argon2i/argon2id`, `bcrypt`, and `md5`.
- Argon2, BCrypt (including TYPO3 mode), and MD5 verification providers.
- Shaded runtime dependencies required for Argon2 verification.
- Test suite for provider behavior and compatibility scenarios.
- Migration-oriented documentation and installation instructions.
